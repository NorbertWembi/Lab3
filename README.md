# LAB 3: HottizaPace

HottizaPace is a simple Star Wars character catalog application developed using Node.js, Express, HTML, CSS, and JavaScript.

The application retrieves Star Wars character information from the SWAPI (Star Wars API) and allows users to browse, search, view, add, and delete character records.

The project demonstrates the implementation of a RESTful API, custom Express middleware, JSON request handling, payload validation, and centralized error management.

## Functionality
User can retrieve and display Star Wars characters from SWAPI, and can search through the characters. User can also add a new character record or delete an existing one. All requests are logged in the console.

## 2. Technologies Used

- Node.js
- Express.js
- JavaScript
- HTML and CSS
- SWAPI (Star wars API) 

HottizaPace uses the following external API: https://swapi.info/api/people
